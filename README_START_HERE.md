## 🎙️ Enable AI Voice Entry (Optional)

To unlock AI features:

1. Get free API key: https://aistudio.google.com/app/apikey
2. Open `.env.local` file
3. Replace `PLACEHOLDER_API_KEY` with your key:
   ```
   GEMINI_API_KEY=your_actual_key_here
   ```
4. Restart: `npm run dev`

Now you can speak your stats and AI will extract them!
